# Python Tasks

A collection of beginner-friendly programming exercises and interview-preparation
notes. The repository includes standalone Python scripts for common algorithms and
patterns, along with question-and-answer files covering DBMS and React.js.

## Contents

### Python exercises

Each script can be run independently with Python 3. Most programs prompt for input
in the terminal.

| File | Description |
| --- | --- |
| [factorial.py](./factorial.py) | Calculate the factorial of a non-negative integer. |
| [count_vowels.py](./count_vowels.py) | Count vowels in a string, ignoring case. |
| [armstrong_number.py](./armstrong_number.py) | Check whether a number is an Armstrong number. |
| [anagram.py](./anagram.py) | Check whether two words or phrases are anagrams, ignoring case and whitespace. |
| [reverse_string.py](./reverse_string.py) | Reverse a string. |
| [second_largest.py](./second_largest.py) | Find the second-largest distinct number in a list. |
| [number_triangle.py](./number_triangle.py) | Print an ascending number triangle. |
| [right_angled_star_triangle.py](./right_angled_star_triangle.py) | Print a right-angled triangle of stars. |
| [inverted_star_triangle.py](./inverted_star_triangle.py) | Print an inverted triangle of stars. |

For example, run an exercise from the repository directory:

```bash
python factorial.py
```

### Interview questions

| File | Description |
| --- | --- |
| [dbms_questions.txt](./dbms_questions.txt) | 70 DBMS questions and answers, from database fundamentals to transactions, indexing, and scaling. |
| [react_js_interview_questions.txt](./react_js_interview_questions.txt) | 50 beginner React.js questions and answers covering components, JSX, props, state, and Hooks. |

- Python 3 for the Python exercises
