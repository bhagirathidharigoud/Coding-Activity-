React.js Interview Questions for Beginners
=========================================

1. What is React?
   React is a JavaScript library for building user interfaces. It helps developers
   create reusable UI parts called components.

2. What is a React component?
   A component is a reusable piece of a user interface. Components can be written
   as JavaScript functions that return JSX.

3. What is JSX?
   JSX is a syntax extension that lets you write HTML-like markup in JavaScript.
   React uses it to describe what should appear on the screen.

4. What is the difference between props and state?
   Props are values passed from a parent component to a child component. State is
   data managed inside a component that can change over time.

5. What is the purpose of the useState Hook?
   useState lets a function component store and update state. It returns the
   current state value and a function for updating it.

6. What is the purpose of the useEffect Hook?
   useEffect lets a function component run side effects, such as fetching data or
   updating a browser feature. It can also run cleanup code when needed.

7. How do you handle an event in React?
   Add an event handler prop such as onClick to a JSX element and pass it a
   function. React event prop names use camelCase.

8. What is conditional rendering?
   Conditional rendering means showing different UI depending on a condition.
   You can use JavaScript expressions such as a ternary operator or && in JSX.

9. Why does React need keys when rendering a list?
   Keys help React identify each item between renders, so it can update the list
   efficiently. Use a stable, unique value for each item's key.

10. What is the Virtual DOM?
    The Virtual DOM is a lightweight representation of the UI that React uses to
    determine what changed and update the browser DOM accordingly.

11. What is a controlled component in React?
    A controlled component is an input whose value is controlled by React state.
    The component updates the state on each change, and the value is rendered from
    state.

12. What is the difference between state and props in simple terms?
    Props are data passed down from a parent component, while state is local data
    stored and managed within a component.

13. What is lifting state up in React?
    Lifting state up means moving shared state to a common parent component so
    multiple child components can access and update the same data.

14. What is the purpose of the useRef Hook?
    useRef lets you keep a value that persists across renders without causing a
    re-render when it changes. It is often used for DOM references or timers.

15. What is the difference between useState and useReducer?
    useState is best for simple state values, while useReducer is useful for more
    complex state transitions and logic spread across multiple actions.

16. How do you fetch data in a React component?
    You can fetch data in a useEffect Hook after the component mounts. The fetched
    data is often stored in state and displayed when it is ready.

17. What is a fragment in React?
    A fragment lets you group multiple elements without adding an extra DOM node.
    You can use <>...</> or React.Fragment.

18. Why should you avoid directly mutating state in React?
    Direct mutation can prevent React from detecting updates properly, which can
    cause stale UI and bugs. Always create new objects or arrays when updating state.

19. What is the purpose of the key prop in a list?
    A key helps React identify which items changed, added, or removed in a list,
    making updates more efficient and predictable.

20. What is the difference between client-side rendering and server-side rendering?
    Client-side rendering builds the UI in the browser after JavaScript loads,
    while server-side rendering generates the HTML on the server before sending it to
    the client.
