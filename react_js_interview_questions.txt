React.js Interview Questions for Beginners
=========================================

1. What is React?
   React is a JavaScript library for building user interfaces. It helps developers
   create reusable UI parts called components.

2. What is a React component?
   A component is a reusable piece of a user interface. Components can be written
   as JavaScript functions that return JSX.

3. What is JSX?
   JSX is a syntax extension that lets you write HTML-like markup in JavaScript.
   React uses it to describe what should appear on the screen.

4. What is the difference between props and state?
   Props are values passed from a parent component to a child component. State is
   data managed inside a component that can change over time.

5. What is the purpose of the useState Hook?
   useState lets a function component store and update state. It returns the
   current state value and a function for updating it.

6. What is the purpose of the useEffect Hook?
   useEffect lets a function component run side effects, such as fetching data or
   updating a browser feature. It can also run cleanup code when needed.

7. How do you handle an event in React?
   Add an event handler prop such as onClick to a JSX element and pass it a
   function. React event prop names use camelCase.

8. What is conditional rendering?
   Conditional rendering means showing different UI depending on a condition.
   You can use JavaScript expressions such as a ternary operator or && in JSX.

9. Why does React need keys when rendering a list?
   Keys help React identify each item between renders, so it can update the list
   efficiently. Use a stable, unique value for each item's key.

10. What is the Virtual DOM?
    The Virtual DOM is a lightweight representation of the UI that React uses to
    determine what changed and update the browser DOM accordingly.

11. What is a controlled component in React?
    A controlled component is an input whose value is controlled by React state.
    The component updates the state on each change, and the value is rendered from
    state.

12. What is the difference between state and props in simple terms?
    Props are data passed down from a parent component, while state is local data
    stored and managed within a component.

13. What is lifting state up in React?
    Lifting state up means moving shared state to a common parent component so
    multiple child components can access and update the same data.

14. What is the purpose of the useRef Hook?
    useRef lets you keep a value that persists across renders without causing a
    re-render when it changes. It is often used for DOM references or timers.

15. What is the difference between useState and useReducer?
    useState is best for simple state values, while useReducer is useful for more
    complex state transitions and logic spread across multiple actions.

16. How do you fetch data in a React component?
    You can fetch data in a useEffect Hook after the component mounts. The fetched
    data is often stored in state and displayed when it is ready.

17. What is a fragment in React?
    A fragment lets you group multiple elements without adding an extra DOM node.
    You can use <>...</> or React.Fragment.

18. Why should you avoid directly mutating state in React?
    Direct mutation can prevent React from detecting updates properly, which can
    cause stale UI and bugs. Always create new objects or arrays when updating state.

19. What is the purpose of the key prop in a list?
    A key helps React identify which items changed, added, or removed in a list,
    making updates more efficient and predictable.

20. What is the difference between client-side rendering and server-side rendering?
    Client-side rendering builds the UI in the browser after JavaScript loads,
    while server-side rendering generates the HTML on the server before sending it to
    the client.

21. What are the rules of Hooks in React?
    Call Hooks only at the top level of a function component or custom Hook, and
    do not call them inside loops, conditions, or nested functions.

22. What is the purpose of the dependency array in useEffect?
    The dependency array tells React when to run an effect again. React compares
    its values with the previous render and reruns the effect when a value changes.

23. What are children props in React?
    The children prop contains the content placed between a component's opening
    and closing tags. A component can render this content using {children}.

24. What is a custom Hook?
    A custom Hook is a JavaScript function whose name starts with "use" and that
    can call other Hooks. It lets you reuse stateful logic between components.

25. What is the Context API used for?
    Context lets components share values, such as a theme or current user, without
    passing props through every level of the component tree.

26. What is the difference between React.memo and useMemo?
    React.memo can skip re-rendering a component when its props have not changed.
    useMemo caches the result of a calculation between renders when dependencies
    stay the same.

27. What is the purpose of useCallback?
    useCallback returns a memoized function and keeps the same function reference
    between renders until one of its dependencies changes.

28. How do you handle forms in React?
    You can handle a form by reading input values from component state or by using
    refs. Add an onSubmit handler and prevent the browser's default form submission
    when handling it in React.

29. What is reconciliation in React?
    Reconciliation is the process React uses to compare the previous UI
    representation with the new one and determine the updates needed in the DOM.

30. What is a portal in React?
    A portal lets you render a component's content into a DOM node outside its
    parent component's DOM hierarchy, while keeping it in the same React tree.

31. What is automatic batching in React?
    Automatic batching groups multiple state updates into a single render, reducing
    unnecessary work. In modern React, this also applies to updates inside promises
    and timers when using a supported root.

32. What is a stale closure in a React component?
    A stale closure happens when a callback uses values captured by an earlier
    render. Use the functional state update form or keep effect dependencies
    accurate when an update needs the latest value.

33. Why should an effect clean up subscriptions or timers?
    Cleanup prevents obsolete subscriptions, timers, or event listeners from
    continuing after an effect is replaced or a component unmounts. Return a cleanup
    function from the effect to release those resources.

34. What is an error boundary, and what can it catch?
    An error boundary is a component that displays fallback UI when a descendant
    throws during rendering. It does not catch errors in event handlers, ordinary
    asynchronous callbacks, or the boundary itself.

35. What does Suspense do in React?
    Suspense displays a fallback while a child is not ready, such as while a
    lazily loaded component is loading. Suspense-enabled data sources can also use
    it, depending on the framework or library.

36. What is hydration in React?
    Hydration attaches React's event handling and behavior to HTML that was
    rendered on the server. The initial client render should match the server HTML
    to avoid hydration errors.

37. How can changing a component's key reset its state?
    React uses a component's type and position, including its key, to identify it.
    Giving it a different key makes React treat it as a new component, resetting
    its local state and recreating its DOM.

38. What is the purpose of useTransition?
    useTransition marks state updates as non-urgent so React can keep the interface
    responsive while working on the update. It returns a pending indicator and a
    function for starting the transition.

39. How does useDeferredValue help with expensive UI updates?
    useDeferredValue lets part of the UI use a deferred version of a changing value.
    React can prioritize urgent updates, such as typing, before rendering the
    expensive content that depends on the deferred value.

40. What is useId used for, and should it be used for list keys?
    useId generates stable IDs for accessibility attributes, such as connecting a
    label to an input. It should not be used for list keys; keys should come from
    the data being rendered.
